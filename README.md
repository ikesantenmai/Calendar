# カレンダー Web アプリ

[English](README.en.md)

予定を入力・管理できる月間カレンダーです。ビルド不要の HTML / CSS / JavaScript だけで動きます。

- **予定の入力** — 追加・編集・削除、終日予定、複数日にまたがる予定、繰り返し、場所・メモ、カレンダー分け、色分け
- **月表示と週の時刻表示** — 日を選ぶと、その週を時間軸付きで表示
- **iPhone のカレンダーのインポート** — iCalendar 形式（`.ics`）の読み込み。公開カレンダーの URL からの取り込みにも対応
- **印刷** — 表示中の月を A4 1 ページに印刷（縦 / 横、時刻・場所の有無、白黒などを選択可能）
- **スマートフォン対応** — iPhone / Android の画面に合わせたレイアウト、スワイプでの月移動、ホーム画面への追加
- **日本語 / English** — 画面の表示言語を切り替え可能（既定は日本語）

## 使い方

`index.html` をブラウザで開くだけです。ファイルをダブルクリックしても、簡易サーバー経由でも動きます。

```sh
# 例：簡易サーバーで開く場合
npx http-server -p 8080 .
# → http://127.0.0.1:8080/index.html
```

対応ブラウザ: Chrome / Edge / Safari / Firefox の最新版（iOS Safari / Android Chrome を含む）。
スマートフォンから使うときは、パソコンで簡易サーバーを立てて同じネットワークからアクセスするか、
任意の静的ホスティングに置いてください。

## 言語（日本語 / English）

既定は**日本語**です。ブラウザの言語設定にかかわらず、初回は日本語で表示されます。

- 切り替え: 画面右上の **「日本語 | English」** の切り替え（スマートフォンでは **⋯** メニューの中）。
  現在の言語が青く表示されるので、どちらの版を見ているか一目で分かり、いつでも戻せます。
  「カレンダー」ダイアログの「言語 / Language」からも変更できます
- 選んだ言語はこのブラウザに保存され、次回もその言語で開きます
- 言語を指定して開く URL:
  - 日本語版 … `/`（既定）または `/ja/`、`?lang=ja`
  - 英語版 … `/en/` または `?lang=en`

  例: `https://<あなたのサイト>.onrender.com/en/` を開くと英語版で表示されます。

> 切り替えても表示が変わらない場合は、ブラウザが古い JavaScript を保持している可能性があります。
> 読み込む URL にバージョン（`?v=…`）を付け、`Cache-Control: no-cache` を指定してあるため
> 通常は自動で更新されますが、それでも変わらないときはページを再読み込みしてください。

切り替えると、画面の文言に加えて月・曜日・日付の表記と日本の祝日名も切り替わります。
すでに入力・取り込んだ予定のタイトルなどは、そのままの言語で保持されます。

## スマートフォンで使う

同じ URL（またはファイル）をスマートフォンのブラウザで開くだけです。画面幅に応じて表示が切り替わります。

- 月表示では予定を**点**で示し、選んだ日の内容は下の一覧に表示します（iPhone のカレンダーと同じ見せ方）
- 日を選ぶと、その週の時刻表示に切り替わります（月表示へは右上の「月」で戻ります）
- カレンダーを**左右にスワイプ**すると前後の月に移動します
- 「インポート／書き出し／カレンダー／印刷」は右上の **⋯** メニューにまとまります
- 予定の追加は右上の **＋**、または一覧の「＋ この日に追加」から
- ダイアログは画面下から出るシート表示になり、入力欄は拡大されないサイズ（16px 以上）にしています
- ノッチやホームバーの領域（セーフエリア）を避けて表示します

**ホーム画面に追加**すると、アプリのように全画面で使えます（iPhone: 共有ボタン →「ホーム画面に追加」、
Android の Chrome: メニュー →「アプリをインストール」）。`manifest.json` とアイコンを同梱しています。

予定のドラッグでの日付変更はマウス操作のみです。スマートフォンでは予定を開いて日付を変更してください。

## 週の時刻表示

**月表示で日を選ぶと、その週が時刻付きで表示されます。**

- 0〜24 時の時間軸に予定を並べ、重なっている予定は横に並べて表示します
- 終日・複数日にまたがる予定は、時間軸の上の「終日」欄にまとめます
- 今日が含まれる週では、現在時刻に赤い線を引きます。表示は現在時刻（今週でなければ 8 時）の位置から始まります
- **空いている時間帯を押すと、その時刻（30 分単位）で予定の追加**が開きます。予定を押すと編集できます
- 曜日の見出しを押すと、その日を選び直せます（右側の一覧が切り替わります）
- 前後の週へは `←` `→` キー、‹ › ボタン、左右スワイプ
- 表示の切り替えは右上の **「月 | 週」**、キーボードは `M`（月）と `W`（週）
- 印刷すると、表示中の週が 1 ページに収まります

## 予定の入力

| 操作 | 方法 |
| --- | --- |
| 追加 | 「＋ 予定を追加」ボタン、週表示で空いている時間帯を押す、`N` キー |
| 編集 | 予定をクリック、または右側の一覧の ✎ |
| 削除 | 予定を開いて「削除」、または一覧の 🗑 |
| 日付の移動 | 予定をドラッグして別の日にドロップ（パソコンのみ・繰り返し予定を除く） |
| 表示の切り替え | 右上の「月 \| 週」、`M` / `W` キー、月表示で日を選ぶ |
| 前後へ移動 | `←` `→` キー、‹ › ボタン、月セレクタ、左右スワイプ（週表示では 1 週間ずつ） |
| 今日へ | `T` キー、「今日」ボタン |

繰り返しは「毎日・毎週・隔週・毎月（同じ日／同じ曜日）・毎年」と終了日の指定に対応しています。
繰り返し予定を削除するときは、**すべての回**か**その日だけ**かを選べます。

日本の祝日（振替休日・国民の休日を含む）は自動で表示されます。「カレンダー」ダイアログでオフにできます。

## iPhone のカレンダーをインポートする

「インポート」ボタンから `.ics` ファイルをドロップします。書き出し方法は次のとおりです。

1. **iCloud 経由（おすすめ・全予定）**
   iPhone の「設定 → Apple ID → iCloud → カレンダー」をオンにし、同じ Apple ID の Mac の
   カレンダー.app で「ファイル → 書き出す → 書き出す…」を選ぶと `.ics` が保存できます。
2. **iPhone だけで（公開カレンダー）**
   カレンダー App →「カレンダー」→ 対象カレンダーの ⓘ →「公開カレンダー」をオン → URL をコピー。
   `webcal://` を `https://` に変えてブラウザで開けば `.ics` が保存できます。
   アプリの「URL から読み込む」に貼り付けても構いません（次の「URL から読み込むときの注意」を参照）。
3. **1 件だけ**
   予定を開く → 共有ボタン → メール等で送信し、添付の `.ics` をドロップします。

### URL から読み込むときの注意

iCloud の公開カレンダー（`webcal://p*-caldav.icloud.com/published/…`）は
`Access-Control-Allow-Origin` を返さないため、**ブラウザから直接は取得できません**（CORS）。
Safari では「Load failed」と表示されます。取り込むには次のどちらかにしてください。

1. **サーバー経由で取得する（Render の Web Service など）**
   `server.js` に中継用の `/api/ics` を用意しています。`npm start` で動かしていれば、
   URL を貼って「読み込む」を押すだけで取り込めます（直接取得を試し、失敗したら自動で
   サーバー経由に切り替えます）。**静的サイトとして公開している場合は中継が無いため使えません。**
   - 中継先は既定で iCloud / Apple / Google / Outlook・Office365 / Yahoo のドメインに限定しています
   - 追加したい配信元があれば環境変数 `ICS_PROXY_ALLOW=host1,host2` に指定します
   - 中継を止めたい場合は `ICS_PROXY=off`
2. **ファイルとして保存して選ぶ（どの公開方法でも使えます）**
   `webcal://` を `https://` に変えた URL をパソコンのブラウザで開くと `.ics` が保存されます。
   保存したファイルをこの画面で選んでください。

インポート時は、新しいカレンダーとして追加するか、既存のカレンダーに統合するかを選べます。
UID が同じ予定は上書き（再インポート時の重複防止）されます。

対応している iCalendar の要素: `VEVENT`、`DTSTART` / `DTEND` / `DURATION`、`VALUE=DATE`（終日）、
`TZID` 付き日時と UTC 日時、`SUMMARY` / `LOCATION` / `DESCRIPTION`、`RRULE`、`EXDATE`、折り返し行、
エスケープ文字。`VALARM`（通知）は読み飛ばします。

### 書き出し

「書き出し」ボタンで、表示中のカレンダーの予定を `.ics` として**ダウンロード**します。
iPhone / iPad では「ファイル」App のダウンロードに保存されます。

- ホーム画面に追加したアプリから開いている場合、Safari はダウンロードができないため、
  自動で共有シートに切り替わります（「ファイルに保存」を選んでください）
- ダウンロードでうまく保存できないときは、「カレンダー」ダイアログの
  **「共有して書き出す」**から共有シート経由で保存できます（対応端末でのみ表示）
- 保存した `.ics` は、メール添付などで送って添付ファイルを開くと iPhone のカレンダーに取り込めます

## 印刷

「印刷」ボタンで、表示中の月（週表示なら、その週）を印刷します。用紙の向き（縦 / 横）、開始時刻・場所の表示、
色付き / 白黒を選べます。A4 1 ページに収まるように調整済みです。
色を紙に出すには、プリンタの設定で「背景のグラフィック（背景を印刷）」を有効にしてください。
`Ctrl` / `⌘` + `P` からも同じレイアウトで印刷できます。

## Render.com へのデプロイ

このアプリは静的ファイルだけで動くため、**Static Site** として公開するのがおすすめです。
その場合 **スタートコマンドは不要**です。

| 項目 | 設定値 |
| --- | --- |
| Language / Runtime | **Static Site** |
| Build Command | （空欄のまま） |
| Publish Directory | `.` |
| Start Command | **不要**（設定欄がありません） |

リポジトリ直下の `render.yaml`（Blueprint）でも同じ内容を定義しています。

> ただし、**「URL から読み込む」で iCloud の公開カレンダーを取り込みたい場合は、
> 静的サイトではなく次の Web Service を選んでください**（中継が必要なため）。
> ファイルを選ぶ取り込み・印刷・予定の入力は、静的サイトでもすべて動きます。

### Web Service として動かす場合

Render の **Web Service**（Node）を選んだときは、次の値を入力します。
`server.js`（依存パッケージなしの静的配信サーバー）を同梱しています。

| 項目 | 設定値 |
| --- | --- |
| Language / Runtime | **Node** |
| Build Command | `npm install` |
| **Start Command** | **`npm start`**（= `node server.js`） |

`npm start` を使わずに 1 行で済ませたい場合は、次のどちらでも動きます。

```sh
node server.js
# または、リポジトリに何も足さずに済ませる場合
npx --yes http-server . -p $PORT -a 0.0.0.0
```

Render は環境変数 `PORT` で待ち受けポートを渡し、`0.0.0.0` で待ち受けることを要求します。
`server.js` はどちらにも対応済みです（`PORT` 未設定なら 3000 番）。

## データの保存先

予定はサーバーに送信されず、ブラウザの `localStorage`（キー `calendar-app:v1`）に保存されます。
別のブラウザや端末とは共有されません。バックアップや移行には「書き出し」を使ってください。
「カレンダー」ダイアログの「すべてのデータを削除」で初期化できます。

## ファイル構成

```
index.html            画面の構造（日本語・英語の共通画面）
en/index.html         英語版の入口 URL（?lang=en へ転送）
ja/index.html         日本語版の入口 URL（?lang=ja へ転送）
manifest.json         ホーム画面に追加するための設定
icons/                アプリアイコン
css/styles.css        画面（パソコン／スマートフォン）と印刷のスタイル
js/i18n.js            日本語 / 英語の文言と日付表記
js/holidays.js        日本の祝日の計算
js/ics.js             iCalendar (.ics) の読み書き
js/store.js           localStorage への保存と繰り返し予定の展開
js/app.js             描画と操作
server.js             Node で配信する場合の静的サーバー（Render の Web Service 用）
render.yaml           Render の Blueprint（静的サイト）
package.json          npm start（= node server.js）
samples/iphone-sample.ics  動作確認用のサンプル
```
